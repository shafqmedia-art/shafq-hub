# نظام شفق ميديا: الملف الشامل (من الألف للياء)

> ملف تسليم كامل لنظام إدارة أعمال **شفق ميديا** (دمشق). اكتبه بأول أي مشروع جديد مع Claude ليعرف كل شي: شو انبنى، كيف مبني، وين كل شي، شو الأدوات، وشو باقي.
> آخر تحديث: 14 تشرين الثاني 2026.

---

## 1. شو هو النظام؟

نظام لإدارة شغل **شفق ميديا** (درون، سوشال ميديا، تغطية مؤتمرات وفعاليات، محتوى، وثائقيات) بهوية شفق:
- **ويب + ويندوز + موبايل** بنفس الكود (تطبيق PWA بينثبّت من المتصفح، بدون متجر).
- **3 أنواع مستخدمين:**
  - **المدير** (عبد الرحمن): بيشوف ويعدّل كل شي.
  - **عضو الفريق** (موظف أو فريلانسر): بيشوف مهامه ودفعاته وملفه بس.
  - **العميل**: بيشوف بوابته بس: خطة النشر، حسابه، ودفعاته. ما بيشوف أسماء الفريق ولا الملاحظات الداخلية.
- عربي بالكامل، من اليمين لليسار، خط **Cairo**، ثيم غامق وفاتح، ألوان شفق (ليموني `#C3FA4F` / أسود / أبيض مكسور).

## 3. البنية التقنية

```
[المتصفح / التطبيق المثبّت]
   index.html + intro.js + app.js + server.js + styles.css + sw.js
        │  (HTTPS, Bearer token)
        ▼
[Supabase]
   ├─ Auth: دخول بالرقم + كلمة السر (bcrypt)
   ├─ Postgres + RLS: الجداول وقواعد الصلاحيات
   ├─ Edge Function "push": إشعارات + إنشاء حسابات + نسيت كلمة السر
   └─ pg_cron + pg_net: تشغيل الدالة كل ساعة (تحيات + منشورات متأخرة)
        │
        ▼
[خدمات الإشعارات: Google FCM / Apple / Mozilla / Microsoft]
```

- **بدون أي مكتبة خارجية:** JavaScript عادي (Vanilla، IIFE)، والتنقل بالـ hash (`#/clients`).
- **وضعين** بـ `config.js`:
  - `mode: "server"` للحقيقي (Supabase).
  - `mode: "local"` للتجربة بدون إنترنت، والبيانات بتنحفظ بالمتصفح (localStorage).
- **المزامنة:** `server.js` بيسحب كل الجداول، وبيقارن التغييرات (snapshot/diff)، وبيدفع بس اللي تغيّر بطابور متسلسل. وفيه تجديد للجلسة مع promise مشترك ليمنع التضارب.
- **PWA:** `manifest.webmanifest` + `sw.js` (كاش للواجهة، الشبكة أولاً). رقم الكاش الحالي **`shafq-shell-v12`**، وبيتزيد مع كل نسخة لتوصل التحديثات.

## 5. كل الأقسام والميزات

### القائمة (للمدير)
- **الرئيسية:** لوحة اليوم، التقويم، المهام
- **العمل:** العملاء، المشاريع، الدرون، خط المحتوى
- **الناس:** الفريق، فريلانس، بنك المؤثرين، العملاء المحتملون، صندوق الطلبات
- **المال:** المالية، الأوراق، التقارير
- **الأدوات:** المعدات (مستأجرة)، التسويق *(ما انبنى)*، ميتا *(ما انبنى)*، المراسل

### التفاصيل
- **الدخول:**
  - بالرقم وكلمة السر (8 أحرف على الأقل).
  - أول مرة بتطلع شاشة «إعداد المدير».
  - شاشة الدخول فيها التحية (صباح/مساء الخير) والساعة كبيرة واليوم والتاريخ الميلادي والهجري، والخانات كبيرة.
- **نسيت كلمة السر:** بيكتب رقمه، فبيوصل إشعار للمدير «طلب كلمة سر جديدة 🔑 · الاسم · الرقم» (حد: مرة كل 10 دقايق للحساب، و30 بالساعة)، وبيطلعله زر «إرسال واتساب» برسالة جاهزة لرقم شفق.
- **شاشة البداية:** مربع ليموني بزوايا منحنية + الشعار، «ش ← شف ← شفق» حرف حرف، ونغمة هادية من 3 نوتات (WebAudio). بتطلع مرة بكل فتحة للتطبيق، وبتنكبس لتتسكّر أسرع.
- **شاشة التحميل:** الشعار + إطار ليموني بيلف + «جارٍ تجهيز مكتبك…».
- **لوحة اليوم:**
  - تحية + ملخص اليوم + الصندوق (الرصيد).
  - شريط «🔔 فعّل الإشعارات».
  - الساعة والتاريخ الميلادي والهجري تحت القائمة على اليمين.
- **العملاء:**
  - عقد شهري أو مشروع، قيمة × أشهر.
  - بصفحة العميل: المقبوض، والباقي، وكلفة الشهر، والصافي.
  - **أدوار مرنة:** سطر واحد بالأول و«+ إضافة دور»، وكل سطر فيه اسم الدور (من قائمة أو جديد) + الشخص + حذف + واتساب «شو صار معك؟».
  - أزرار: «إنشاء دخول للعميل» / «إيقاف دخول العميل» / «كلمة سر العميل» / «إرسال إشعار».
- **بوابة العميل:**
  - خطة النشر الشهرية مقسومة على 4 أسابيع (الحالي مفتوح والباقي مطوي)، وتنقّل بين الأشهر، وتقدّم حسب النوع.
  - حالات: نزل / جاهز للنشر / قيد التحضير / **متأخر** (فات موعده وما انحط «منشور»)، والمتأخر جنبه زر «شو صار معكم؟ · واتساب» لرقم شفق.
  - الحساب: قيمة العقد، المدفوع، الباقي، **الدفعة الجاية**.
  - جدول دفعات: التاريخ، «عن شو»، المبلغ، رقم الوصل، الحالة (مدفوعة/مستحقة).
  - البيانات بتجي من دالة `client_portal()` بس.
- **الفريق:**
  - موظف/فريلانسر، الصفة (قائمة: مصور، مصمم، مونتير، كونتنت كريتر، كاتب محتوى، درون بايلوت، مدير إعلانات، فيلم ميكر، وجه إعلامي، موشن جرافيك، معلّق صوتي…)، **الجنس** (رسائل بصيغة المؤنث/المذكر)، قيمة العقد، المدفوع، الباقي.
  - أزرار: دفع له، تعديل (فيه «كلمة سر جديدة»)، إيقاف، «شو صار معك؟ · واتساب»، **«إرسال إشعار»**.
- **إرسال إشعار يدوي:** قائمة رسائل جاهزة.
  - **للعضو:** شو صار معك؟، وصلك الدفع؟، عندك مهمة جديدة، تذكير بالتسليم، يعطيك العافية.
  - **للعميل:** شو صار معكم؟، تذكير بالدفعة الجاية (مع التاريخ والمبلغ)، وصلتنا دفعتكم، محتوى بانتظار موافقتكم، خطة الشهر جاهزة.
  - وخيار «رسالة أخرى…» للكتابة الحرة. النص بيتعدّل قبل الإرسال.
- **المالية:**
  - العرض بالدولار، والإدخال بالدولار أو بالليرة (السوري القديمة) مع سعر صرف يومي بينحفظ مع كل حركة.
  - «عن شو» (إدارة صفحة، إدارة إعلانات، تصوير، مونتاج، تصميم، وجه إعلامي، كتابة محتوى، درون، تغطية فعالية + أي خدمة جديدة).
  - **وصل قبض تلقائي RCV** لكل دفعة من عميل، وبينعمل ورقته بالأوراق.
  - **ما في حذف:** الحركة بتنلغى، والملغاة فيك تحذفها نهائياً.
- **الأوراق:** INV فاتورة، QUO عرض سعر، RCV وصل قبض، PAY وصل دفع، DLV وصل استلام مواد، LOG سجل فرز الداتا، FRL عقد فريلانس، EMP عقد موظف، CLT عقد عميل. الترقيم `CODE-YYYY-NNN`، وبتنلغى بس (ما بتنحذف).
- **خط المحتوى:**
  - الحالات: فكرة ← كتابة ← تصميم أو مونتاج ← موافقة العميل ← مجدول ← منشور.
  - الأنواع: بوست، ريل، كاروسيل، ستوري، منشور الجمعة.
  - تاريخ + **ساعة النشر**.
  - **إكسل:** «تحميل قالب إكسل» (بقوائم منسدلة فيها العملاء الحاليين والأنواع والفريق والحالات) و«رفع ملف إكسل»، فبتنضاف المنشورات دفعة وحدة. بيقبل التاريخ بأي شكل والأرقام العربية وأخطاء الإملاء بالأسماء، وما بيكرر المنشورات الموجودة. (قارئ وكاتب xlsx مكتوب يدوياً بدون مكتبات.)
- **الملف الشخصي:** الصورة، البيانات، الجنس، تغيير كلمة السر، **الإشعارات** (تفعيل / إشعار تجريبي مع سبب الفشل إذا فشل)، **رقم شفق للواتساب**، و**سجل النشاط** (آخر 60).
- **الأقسام التانية:** المشاريع، الدرون، فريلانس، بنك المؤثرين، العملاء المحتملون (مع تحويل لعميل)، صندوق الطلبات، المعدات المستأجرة، التقويم، التقارير، المراسل.

### الإشعارات (Web Push)
- **تحيات تلقائية** الساعة 8 الصبح و9 المسا (توقيت دمشق) بالاسم والصيغة الصح:
  - العضو: «صباح الخير أستاذ أحمد ☀️ · عندك اليوم مهمتين».
  - المدير: كم مهمة مفتوحة للفريق وكم منشور بالخطة.
  - العميل: كم منشور إلهم اليوم.
- **أحداث:**
  - مهمة جديدة ← للعضو.
  - عضو أنجز مهمة ← للمدير.
  - دفعة من عميل ← للعميل (المبلغ، عن شو، رقم الوصل).
  - دفعة لعضو ← إله.
  - منشور صار «منشور» ← للعميل.
- **منشور متأخر** ← للمدير والمسؤول، مرة وحدة (العميل ما بيوصله).
- **الآيفون:** لازم يضيف النظام للشاشة الرئيسية قبل التفعيل.
- **الواتساب الأوتوماتيكي ممنوع من سوريا:** منصة واتساب للأعمال ما بتخدم سوريا، فأزرار الواتساب يدوية (بتفتح المحادثة برسالة جاهزة).

## 6. الأمان (المراجعة الكاملة)
- **صلاحيات قاعدة البيانات (RLS)** على كل الجداول. انجرّب كاختراق من عضو وعميل وغريب وزائر، وكله انرفض.
- **إنشاء الحسابات على السيرفر** (المدير بس)، فبتقدر تطفّي التسجيل العام بـ Supabase.
- **CSP** + تحويل HTTPS + منع الإطارات + `nosniff` + `referrer`.
- **الحماية من XSS:** كل النصوص بتمرق من `h()`. انجرّب كود خبيث بـ 112 خانة و19 صفحة، وما اشتغل.
- **حدود:** المبالغ موجبة، والعملة USD/SYP بس، وأطوال النصوص، والصورة أقل من 300 كيلو، والإكسل أقل من 5 ميغا و3000 سطر.
- **دالة push:** CORS لموقعك بس، والـ cron من السيرفر بس، و«نسيت كلمة السر» عليه حد طلبات، وروابط الإشعارات للخدمات الرسمية بس.
- **سجل نشاط** ما بينمسح من التطبيق (بيحتفظ 180 يوم).
- **تاريخ GitHub نظيف**، ومفاتيح الإشعارات انبدّلت بعد ما بيّنت بصورة شاشة.
- **التقرير الكامل:** https://claude.ai/artifact/75sSEewhgHndpv5iUkKhfE

**إعدادات لازم تكون مفعّلة:**
- Supabase ← Authentication: «Confirm email» مطفي، و«Allow new users to sign up» **مطفي** (بعد نشر الدالة الجديدة)، و Rate Limits.
- GitHub ← Pages: «Enforce HTTPS».
- التحقق بخطوتين (2FA) على GitHub و Supabase.

## 7. طريقة التحديث (كل مرة)
1. **ملفات الموقع:** GitHub ← `shafq-app` ← Add file ← Upload files ← اسحب **الملفات اللي جوا المجلد** (مو المجلد) ← Commit changes.
2. **ملف SQL جديد:** Supabase ← SQL Editor ← **+** (استعلام جديد) ← الصق الملف لحاله ← Run.
3. **دالة push:** Edge Functions ← push ← Code ← الصق ← Deploy.
4. **ليوصل التحديث للأجهزة:** زيد رقم الكاش بـ `sw.js`، وعلى الجهاز سكّر التطبيق وافتحه مرتين (أو Ctrl+Shift+R). التأكد: افتح `.../shafq-app/sw.js` وشوف رقم الإصدار.
5. **الأيقونة على أندرويد** بتتحدّث بس إذا حذفت التطبيق ورجعت ثبّتته.

**تثبيت التطبيق:**
- **أندرويد:** كروم ← الرابط ← ⋮ ← «تثبيت التطبيق».
- **آيفون:** سفاري ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
- **ويندوز:** كروم أو إيدج ← أيقونة التثبيت بشريط العنوان.

## 9. اللي ما انبنى بعد (الأفكار الجاية)
- **سعر الصرف التلقائي من «الليرة اليوم» (sp-today.com):** بدها مفتاح مجاني من https://api-v2.sp-today.com/api-dashboard/signup، وبينحط بـ Secrets ودالة push بتجيبه كل صبح. (الليرة الجديدة = القديمة ÷ 100.)
- **التسويق** و**ميتا** (ربط صفحات فيسبوك وإنستغرام).
- **قراءة لقطات الشاشة** (ملء بنك الفريلانس والمؤثرين من صور إنستغرام).
- **طباعة الأوراق** (فواتير، عقود، وصولات بهوية شفق).
- **المساعد العربي** داخل النظام.
- **بوت تيليغرام** (بديل مجاني للواتساب الأوتوماتيكي).
- **Google Play:** ممكن تحويله لـ AAB (TWA). بدّه حساب 25$ و12 مجرّب لمدة 14 يوم، وتتأكد إنه سوريا مدعومة بالتسجيل.
- **دومين خاص** (مثلاً `app.shafq.art`) موجّه على GitHub Pages.

## 10. قرارات وتفضيلات مهمة
- الكلام والواجهات **باللهجة السورية**، والرسائل محترمة («أستاذ/أستاذة»، «يعطيك العافية»).
- كل العملات **بالدولار** بالعرض، والليرة بالإدخال بسعر يوم الحركة.
- **ما في حذف للمال ولا للأوراق:** إلغاء، وبعدها حذف نهائي للملغى بس.
- العميل **ما بيشوف أسماء الفريق** ولا الملاحظات الداخلية.
- «متأخر» = فات التاريخ والساعة، والحالة مو «منشور».
- الواتساب بيروح لـ `shafq_phone` (من الملف الشخصي)، وإذا مو محدد، لرقم المدير.
- المنطقة الزمنية **Asia/Damascus (UTC+3)**.
